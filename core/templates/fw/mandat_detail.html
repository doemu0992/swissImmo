{% comment %} RENTABILITÄT — UND WORAUF SIE BERUHT Der Prototyp notierte zu dieser Karte: «Das ist eine Zumutung an den Alltag … Ob deine Leute das mitmachen, kann nur jemand entscheiden, der das Büro kennt.» Und: Eine Kennzahl aus geschätzten Stunden wäre schlimmer als keine. Deshalb steht die Abdeckung DANEBEN, nicht im Kleingedruckten: Bei zwei von neunzehn Fällen mit erfasster Zeit ist «CHF 340 pro Stunde» kein Ergebnis, sondern ein Zufall. Fehlt der Stundensatz oder die Zeit, steht dort der GRUND — nicht «CHF 0.00». Eine Null wäre eine Aussage, die niemand getroffen hat. {% endcomment %} {% comment %} «WAS AUFFÄLLT» — ÜBERSCHRIFT, ZÄHLER, UND VOR DEM INHALT (E2.64) Konzept v7 zur Akte: «Deckblatt mit gerechneten Zuständen, ‹Was auffällt› VOR dem Inhalt, ein Reitersatz für alle Typen.» Die Hinweise gab es hier bereits — mit Ton, Zeichen und Handlungsknopf. Eine fehlende IBAN unter den Stammdaten liest man erst, wenn man ohnehin schon scrollt.
