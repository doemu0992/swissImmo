{% trans "Merkblatt: Richtig Lüften und Pflegen" %}

{% trans "Hinweise zur Vermeidung von Feuchtigkeits- und Schimmelschäden" %}

{% trans "Jeder Haushalt gibt täglich mehrere Liter Feuchtigkeit an die Raumluft ab (Kochen, Duschen, Wäschetrocknen, Atmung, Pflanzen). Wird diese Feuchtigkeit nicht regelmässig abgeführt, entsteht Schimmel. Mit dem richtigen Lüften und Heizen beugen Sie Schäden vor." %}

{% trans "Richtig Lüften" %}
  • {% blocktrans trimmed %}Stosslüften statt Kippen: Fenster mehrmals täglich für 5–10 Minuten ganz öffnen (Durchzug), statt sie dauerhaft gekippt zu lassen.{% endblocktrans %}
  • {% blocktrans trimmed %}Querlüften: Gegenüberliegende Fenster gleichzeitig öffnen — so wird die Luft am schnellsten ausgetauscht.{% endblocktrans %}
  • {% blocktrans trimmed %}Nach Feuchtigkeit lüften: Nach dem Duschen, Baden und Kochen sofort lüften. Türen zu feuchten Räumen geschlossen halten.{% endblocktrans %}
  • {% blocktrans trimmed %}Schlafzimmer: Morgens nach dem Aufstehen gründlich lüften.{% endblocktrans %}
{% trans "Richtig Heizen" %}
  • {% trans "Alle Räume auf mindestens 17–18 °C temperieren, auch selten genutzte Zimmer." %}
  • {% trans "Heizkörper nicht mit Möbeln oder Vorhängen verdecken." %}
  • {% trans "Während des Lüftens die Thermostatventile herunterdrehen." %}
{% trans "Feuchtigkeit vermeiden" %}
  • {% trans "Wäsche möglichst nicht in der Wohnung trocknen; falls doch, gut lüften." %}
  • {% trans "Möbel mit einigen Zentimetern Abstand zur Aussenwand aufstellen, damit die Luft zirkulieren kann." %}
  • {% trans "Dunstabzug bzw. Ventilator in Küche und Bad nutzen." %}
{% trans "Pflege der Wohnung" %}
  • {% trans "Oberflächen, Armaturen und Silikonfugen regelmässig reinigen." %}
  • {% trans "Abläufe und Siphons frei halten." %}
  • {% trans "Schäden und Mängel umgehend der Verwaltung melden." %}

{% trans "Bei Fragen zur richtigen Pflege Ihrer Wohnung steht Ihnen die Verwaltung gerne zur Verfügung." %}
